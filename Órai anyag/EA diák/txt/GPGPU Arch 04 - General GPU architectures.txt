GPU origins
●   Initially, GPU-s were only used for graphics, to speed up the execution of the
    so called graphics pipeline
●   In the beginning, not even the entire computation was placed on the GPU die:
    only rasterization onwards was hardware accelerated (3dfx Voodoo cards),
    prior stages (transformations, etc.) had to be carried out by the CPU
●   Many stages of the graphics pipeline can be formulated such that we carry
    out the same operation on multiple different data => SIMD processing
●   GPU-s were shaped to accommodate such needs
●   It took several years and GPU generations for general purpose computations
    to be first class citizens on the GPU
GPU evolution
●   The first generations of GPU-s had special processing units for the various
    stages of the graphics pipeline
●   These were different compute units with different sets of instructions
●   Then the compute units became unified (first on ATI (now acquired by AMD)
    then on NVIDIA) => no more separate vertex and pixel shader units, only
    ‘compute units’ (CUDA cores on NVIDIA)
